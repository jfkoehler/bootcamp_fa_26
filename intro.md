# Data Bootcamp

## Fall 2026

Data Bootcamp is a practical introduction to using data to answer economic and business questions. The course connects technical work in Python with problem framing, careful analysis, reproducible workflows, and clear communication.

The course begins by asking what makes a data challenge useful:

- Who is the stakeholder?
- What decision needs to be made?
- What data is available, and what is missing?
- How can the data support the decision?
- What should the analysis deliver?

We then build the tools needed to answer those questions, beginning with Unix and Git before moving into Python, pandas, visualization, statistics, machine learning, and deployment.
